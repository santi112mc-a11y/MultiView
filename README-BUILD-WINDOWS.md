# MultiView V14 TEST

Esta compilación tiene un nombre y paquete distintos para garantizar que Windows instale una aplicación nueva y no reutilice la instalación anterior.

1. Reemplazá los archivos del repositorio por estos, sin borrar `.git`.
2. Subí los cambios a GitHub.
3. Ejecutá Actions -> Build Windows.
4. Instalá el Setup.exe del artefacto.
5. La ventana debe decir **MultiView V14 TEST**. Si no dice eso, se está abriendo una instalación anterior.

Después probá: Panel 1 = Formula Timer y Panel 2 = TVLibre.
